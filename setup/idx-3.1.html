Quick Start

1. Power up for the first time Plug IDX into a standard 5v USB-C power supply using the rear USB socket.

IDX will glow white, then cyan as the needle calibrates. The LEDs then flash deep blue for one second — this indicates WiFi is not yet configured.

The needle will start walking on its own. This is Display MODE, the factory default. No setup is needed for it to run.
2. Connect to temporary WiFi access point IDX will create a temporary WiFi network for configuration.

On your phone or computer, join the WiFi network named IDX-<serial>-setup — for example IDX-3-102-setup. Check the rear of the unit for your Serial Number.

Use the password: idxsetup

A window should open automatically. If not, visit http://192.168.4.1 in your browser.

Note: the setup network closes after 5 minutes if unused, as a security precaution. To reopen it, unplug IDX and plug it back in.
3. Configure WiFi In the IDX WiFi Setup page, once the WiFi scanning has completed, select your SSID from the list and enter your WiFi password. Click Connect.

The setup page will then show the device's local address, along with the login details you'll need in step 4.

This address is used to access the IDX Dashboard where you can configure the data source, ambient lighting and other settings.

Copy the address, then finish setup. IDX restarts onto your own network.
4. Access IDX Dashboard Ensure your phone/computer is back on your main WiFi network.

Wait 30 seconds for IDX to complete its initialisation.

Visit the copied address in your browser. The dashboard asks for a login — the username is idx and the default password is idxsetup. You can set your own password later under ADVANCED.

Backup Option: If the address is not found, locate IDX's assigned IP address using your router admin page or a network scanner (like Fing). Look for "IDX" or "Espressif". Enter it into a browser address bar.
5. Configure IDX Out of the box, IDX runs Display MODE — the needle walks the dial with no data source. Now that you're on WiFi, you can choose a data source instead.

Select MODE to choose what data source IDX should use. Select AMBIENCE to adjust the lighting effect, including night mode.
6. Fit a face insert IDX's dial face accepts a swappable, printed face insert so the scale matches your chosen MODE.
