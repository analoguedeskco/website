Quick Start

The microprocessor inside your INDEX-01 is small and efficient. Please allow it time to wake up and load web pages.

1. Power Up Plug the device into a standard USB-C port (5V).
⚠️ Use a standard 5V adapter or computer port.
2. Connect On your phone or computer, join the WiFi network named INDEX-SETUP. A window should open automatically. If not, visit http://192.168.4.1 in your browser.
3. Configure WiFi In the WiFiManager page, enter your WiFi details. The page will close as the device connects to WiFi..-
4. Access the INDEX-01 Interface Find the device's IP address in your router's connected devices list, then enter it into your browser to access the full configuration interface.
5. Configure INDEX-01 Select `Configure Mode` to choose what the INDEX-01 should track.
