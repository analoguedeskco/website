Quick Start

1. Power up for the first time Plug INDEX into a standard 5v USB-C power supply using the rear USB socket.

INDEX will glow white, then blue. This indicates it's ready for WiFi setup.
2. Connect to temporary WiFi access point INDEX will create a temporary WiFi network for configuration.

On your phone or computer, join the WiFi network named INDEX-01-setup. A window should open automatically. If not, visit http://192.168.4.1 in your browser. Use the password: analoguedeskco
3. Configure WiFi In the WiFiManager page, choose CONFIGURE WIFI, select your SSID from the list and enter your WiFi password. Click Save. The page will close as INDEX connects to your WiFi.

INDEX will now glow light blue (connecting to WiFi) and green (needle initialising).
4. Access INDEX Dashboard Ensure your phone/computer is back on your main WiFi network.

Wait 30 seconds for INDEX to complete its initialisation.

Visit http://index.local in your browser (assuming you've not changed the device name).

If it doesn't load, wait a few minutes and try again.

Backup Option: If it still doesn't load, find INDEX's assigned IP address using your router admin page or a network scanner (like Fing). Look for "INDEX-01" or "Espressif". Enter it into a browser address bar.
5. Configure INDEX-01 By default, INDEX-01 is set to track the current time.

Select MODE to choose what data source INDEX-01 should use. Examples:
  • TIME - A simple clock function
  • CRYPTO - Cryptocurrency price trends (BTC, ETH, etc.), Fear & Greed
  • STOCKS - Stock price trends (AAPL, TSLA, etc.)
  • TEMPERATURE - The current temperature in your location.
Select AMBIENCE to adjust the lighting effect.
